## ✨ Features

- 🔢 Floating on-screen numeric keypad
- ⚡ Quick access to numbers
- 🐧 Designed for Linux desktops
- 🚀 Simple Python launch

## 📥 Installation

### Step 1: Clone the Repository

```bash
git clone YOUR_REPOSITORY_URL
cd YOUR_REPOSITORY_NAME
```

### Step 2: Run the Application

```bash
python3 numpad.py
```

### Alternative: Download Using cURL

```bash
curl -L "YOUR_RAW_FILE_URL" -o numpad.py
```

### Step 3: Launch the Script

```bash
python3 numpad.py
```

## 💻 Requirements

- Linux
- Python 3

Check Python:

```bash
python3 --version
```
